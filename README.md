# AI Agent

QA-оркестратор для автоматизации ревью требований, создания задач Jira и интеграции с testomat.io, Confluence и Jira.

## Обзор

Проект реализует многоагентную систему оркестрации QA, которая:

- Принимает требования из страниц Confluence
- Проверяет и валидирует артефакты
- Автоматически создаёт задачи в Jira
- Интегрируется с testomat.io для управления тестами
- Возвращает структурированный результат со статусом, ID и проблемами

## Требования

- Java (JDK 11 или выше)
- IntelliJ IDEA (проект настроен как IDEA-модуль)
- Доступ к:
  - Atlassian MCP endpoint (Jira + Confluence)
  - API testomat.io
- Действительные учётные данные для всех интегрированных сервисов

## Конфигурация

### MCP-серверы

Настройте MCP-эндпоинты в `opencode.json`:

```json
{
  "mcp": {
    "servers": {
      "jira": {
        "type": "remote",
        "url": "https://mcp.atlassian.com/v1/mcp"
      },
      "confluence": {
        "type": "remote",
        "url": "https://mcp.atlassian.com/v1/mcp"
      }
    }
  }
}
```

### Аутентификация

Установите переменные окружения или настройте учётные данные для:

| Сервис         | Требуемые учётные данные       |
|----------------|--------------------------------|
| Jira           | API-токен / OAuth              |
| Confluence     | API-токен / OAuth              |
| testomat.io    | API-ключ                       |

## Использование

### Формат входных данных

Предоставьте следующие входные данные оркестратору:

| Параметр               | Описание                              | Пример                               |
|------------------------|---------------------------------------|--------------------------------------|
| `taskPrompt`           | Описание задачи                       | `"Ревью требований спринта 12"`      |
| `confluenceUrl` / `ids`| URL или ID страницы Confluence        | `"https://wiki/page/123"`            |
| `jiraProjectId`        | ID проекта Jira                       | `"PROJ"`                             |
| `testomatProject`      | Имя / ID проекта testomat.io          | `"test-project"`                     |
| `additionalParams`     | Дополнительные параметры              | `{}`                                 |

### Рабочий процесс

1. **Принять входные данные** — предоставьте Task Prompt, ссылки Confluence, ID Jira/testomat
2. **Запустить QA-оркестратор** — агент обрабатывает входные данные и запускает субагенты
3. **Получить результат** — структурированный вывод содержит:
   - Статус выполнения (`SUCCESS` / `PARTIAL` / `FAILED` / `REQUIRES_HUMAN_DECISION`)
   - ID созданных задач Jira
   - ID созданных тестовых сущностей testomat.io
   - Обнаруженные неоднозначности и конфликты
   - Блокировки и ошибки
   - Частично выполненные операции (если есть)

### Запуск агента

Откройте проект в IntelliJ IDEA:

```powershell
# Открыть в IntelliJ
idea .
```

Или запустите из командной строки (если существует исполняемый файл):

```powershell
# Проверьте доступные скрипты запуска
ls *.sh *.bat 2>$null

# Типичный запуск (настройте под вашу среду)
java -jar AI_Agent.jar --input inputs.json
```

## Правила агента

Агент строго следует правилам, описанным в `AGENTS.md`:

**Разрешено:**
- Принимать входные данные
- Вызывать субагент QA-оркестратора
- Возвращать результаты от QA-оркестратора

**Запрещено:**
- Прямое взаимодействие с Confluence, Jira, testomat.io
- Валидация артефактов
- Логика ревью требований
- Создание тест-дизайна
- Изменение статусов

## Артефакты

Генерируемые артефакты хранятся в директории `artifacts/`:

- **`jira-tasks/`** — определения задач Jira и ID
- **`requirement-review/`** — результаты анализа требований
- **`test-model/`** — результаты тестового дизайна и моделирования

## Устранение неполадок

| Проблема                         | Решение                                                   |
|----------------------------------|-----------------------------------------------------------|
| Ошибка подключения MCP           | Проверьте URL в `opencode.json` и сетевой доступ          |
| Ошибка аутентификации            | Проверьте API-токены / OAuth-учётные данные для каждого сервиса |
| Не удалось создать задачу Jira   | Проверьте права на создание задач в проекте               |
| Ошибка интеграции testomat       | Убедитесь в правильности API-ключа и имени проекта        |
