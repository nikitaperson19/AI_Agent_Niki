# TC-01: Выбор одного допустимого файла через кнопку «Выбрать файл»

**Priority:** high
**Type:** positive

**Preconditions:** Форма загрузки файла открыта

**Steps:**
1. Нажать кнопку «Выбрать файл»
2. В открывшемся диалоговом окне выбрать файл формата .pdf размером 1 МБ
3. Подтвердить выбор

**Expected result:** Файл успешно добавлен в форму. Файл отображается в списке прикреплённых файлов.
